# 9 号 · 图表可视化模块

文件：`static/js/chart.js`（自研 Canvas，无第三方依赖）

> 原计划是把 Chart.js 下载到 `static/vendor/`，下载失败再手写 canvas 版。
> 这里直接采用手写版：现场没网也能跑，接口完全按 CONTRACT.md 定死，
> 也不会出现两个库抢 `window.Chart` 的问题。**index.html 里不要再引 Chart.js。**

---

## 一、对外接口

```js
BookApp.chart.pie (el, data, opts)   // 饼图 / 环形图
BookApp.chart.bar (el, data, opts)   // 柱状图
BookApp.chart.line(el, data, opts)   // 折线图
BookApp.chart.destroy(el)            // 销毁某容器上的图（切换视图时调用）
BookApp.chart.colors(n)              // 取 n 个分类色，给自绘图例用
BookApp.chart.into(anchor, data, opts)  // 在锚点旁边自动建容器并画图，见第四节

// 也可以简写成 Chart.pie / Chart.bar / Chart.line（window.Chart 别名）
```

- `el`：容器元素或选择器字符串（`'#chart-expense'`）
- 返回值：实例 `{ update(data), destroy() }`
- 同一个容器重复调用会自动销毁旧图，不用手动清理

## 二、数据格式

统一 `[{label, value}]`。为了少踩坑，下面这些键名也能直接认：

| 传进来 | 认成 label | 认成 value |
|---|---|---|
| `{label, value}` | label | value |
| `{category, amount}` ← 7 号 | category | amount |
| `{period, expense}` ← 6 号 | period | expense |
| `{bucket, count}` ← 8 号 | bucket | count |

多系列（比如收入/支出同时画）：

```js
BookApp.chart.line(el,
  [{ period:'11-01', income:8000, expense:230 },
   { period:'11-02', income:0,    expense:180 }],
  { series: [
      { key:'income',  name:'收入', color:'#008300' },
      { key:'expense', name:'支出', color:'#e34948' }
    ] }
);
```

> `color` 也可以传 CSS 变量（`'var(--viz-income)'`），模块内部会查一次真值——
> Canvas 本身不认 `var()`，直接塞进去会静默变成黑色。

## 三、挂载（10 号已提供 `.chart-box`）

`style.css` 里已经有现成的容器，直接用：

```html
<div class="chart-box" id="chart-expense"></div>
```

```js
BookApp.chart.pie('#chart-expense', data);
```

- `.chart-box` 是 `min-height:240px`，模块会先量高度再插画布，**不要**再给它写死高度；
  要改图表高度就传 `opts.height` 或给容器设 `height`。
- 容器是 `position:static` 时模块会自动改成 `relative`，不用额外写样式。
- 容器宽度变化会自动重绘（ResizeObserver），不用监听 `window.resize`。
- 视图切换时先 `BookApp.chart.destroy('#chart-expense')`，避免旧图残留。

## 四、和 6/7/8 号怎么接

### 7 号（分类统计）—— 已经自动接上了

7 号在 `stats-category.js` 里把数据挂到 `BookApp.categoryChartData`，并派发 `categoryStatsUpdated` 事件，但页面里没有图表容器。所以我这边监听这个事件，**自己往 `#category-list` 前面插一个 `.chart-box` 再画饼图**——

```js
window.addEventListener('categoryStatsUpdated', function (e) {
  var data = e.detail || BookApp.categoryChartData || [];
  if (data.length) Chart.into('#category-list', data, { id: 'chart-category', type: 'pie' });
});
```

7 号不用改任何代码，PR 合进来就自动出图。视图来回切换也不会重复插容器（用 `isConnected` 判断）。

### 6 号（时间维度统计）—— 已经接上，零改动

6 号在 `stats-date.js` 里自己建了容器，并在数据回来时主动调用：

```html
<div class="chart-box" id="chart-expense"></div>
```
```js
window.BookApp.chart.bar('#chart-expense', chartData);   // chartData = [{label: period, value: expense}]
```

这个写法和模块接口完全对得上，**6 号不用改任何代码**，PR 合进来就直接出图。

实测覆盖了三种粒度：

| 粒度 | period 长这样 | 表现 |
|---|---|---|
| 日（默认） | `2026-11-01` | ≤10 根柱子，标签横排 |
| 日（放宽区间） | `2026-11-01` | 38 根柱子，标签斜排，自动缩成 `10-01` 避免越界 |
| 周 | `2026-W44` | 标签横排 |
| 月 | `2026-11` | 标签横排 |

> 日粒度下柱子一多，`2026-10-01` 斜着排有 58px 长，末端会从画布底边漏出去。
> 模块在斜排时会剥掉所有标签共有的年份前缀（跨年时前缀不一致则原样保留），
> 底部留白也按斜排实际占用高度算。**悬停提示里仍是完整日期**，只有轴上做缩略。

### 8 号（金额分布）—— 一行接入

如果 8 号不想自己写容器，调这一行：

```js
BookApp.chart.into('#某个锚点元素', data, { id: 'chart-xxx', type: 'pie' });  // type 可为 pie/bar/line
```

图表会插在锚点元素前面，容器用 10 号 `.chart-box` 的样式。锚点不存在时静默跳过，不会报错。

## 五、参数

| 参数 | 说明 | 默认 |
|---|---|---|
| `height` | 画布高度 px | 插入画布前量到的容器高度，兜底 260 |
| `donut` | 饼图是否挖空 | `true` |
| `showValues` | 柱顶标数值 | 柱数 ≤ 10 且单系列时开 |
| `area` | 单系列折线加淡填充 | `true` |
| `currency` | 提示框金额前缀 | `'¥'` |

## 六、配色

颜色优先走 CSS 变量，10 号在 `style.css` 里定义即可整站换肤；
不定义就用模块内置默认色（已跑过校验器）。目前 `style.css` 还没定义，走默认。

```
--viz-series-1 … --viz-series-8   8 个分类色，固定顺序取用，不循环生成
--viz-income  --viz-expense       收入 / 支出
--viz-surface --viz-ink --viz-ink-2 --viz-muted --viz-grid --viz-axis
```

**校验结论（用校验器跑过，不是凭感觉）：**
- 8 个分类色，明暗两套下相邻对色盲 ΔE 最小 9.1 / 8.4，正常视觉 ΔE 最小 19.6 / 19.3，全部过线；
- 收入绿 ↔ 支出红色盲 ΔE 仅 **7.2**，处在 6–8 警戒带——所以图例和提示框**必须带文字**，
  不能只靠红绿区分。代码里已保证：≥2 个系列必有图例，饼图必有图例 + 百分比。
- 明色下青、黄、粉三色对白底对比度 < 3:1，所以饼图直接标了最大扇区的百分比，
  图例里也带百分比，不依赖纯色块识别。
